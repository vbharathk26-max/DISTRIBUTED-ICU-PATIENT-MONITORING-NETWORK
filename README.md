# DISTRIBUTED ICU PATIENT MONITORING NETWORK

## 📌 Project Overview

The Distributed ICU Patient Monitoring Network is a healthcare monitoring system designed to continuously monitor patients' vital health parameters in an Intensive Care Unit (ICU).

The system collects patient health information through monitoring sensors and makes the data available to healthcare professionals. It helps doctors and nurses observe multiple patients from a centralized monitoring system and identify abnormal conditions.

## 🎯 Objectives

- To continuously monitor patients' vital health parameters.
- To collect and process patient health data.
- To enable centralized monitoring of multiple ICU patients.
- To identify abnormal health conditions.
- To improve patient monitoring and support timely medical attention.

## ⚙️ Key Features

- Real-time patient health monitoring.
- Centralized monitoring of multiple patients.
- Continuous collection of sensor data.
- Abnormal condition detection.
- Improved communication between monitoring units and healthcare professionals.

## 🏗️ System Architecture

The system consists of the following major components:

1. Patient Monitoring Unit
2. Health Monitoring Sensors
3. Data Processing Unit
4. Communication Network
5. Central Monitoring Station

## 🔄 Working Principle

1. Sensors collect patients' vital health parameters.
2. The collected data is transferred to the processing unit.
3. The processing unit analyzes the received information.
4. Patient data is transmitted through the communication network.
5. The central monitoring station displays the health information.
6. Abnormal readings can be identified for further medical attention.
